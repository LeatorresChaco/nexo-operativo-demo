# Nexo Operativo — 3 demos públicas

Tres versiones funcionalmente equivalentes de una demo pública de gestión operativa con datos 100% sintéticos.

## Versiones

1. `01_azul_futurista/` — SaaS tecnológico azul/cian.
2. `02_agro_editorial/` — editorial claro, verde/tierra.
3. `03_carbon_naranja/` — oscuro premium con naranja y esmeralda.

## Funcionalidades incluidas

- 28 gestiones sintéticas.
- 6 KPI, incluido monto completado.
- Atención sugerida con etiquetas comprensibles (sin P1/P2/P3/P4).
- Distribución por estado clickeable.
- Alertas y riesgos.
- Búsqueda global y filtros combinables.
- Tabla completa de gestiones.
- Drawer de detalle por caso.
- Exportación CSV de la vista filtrada.
- Explicación de qué demuestra y qué no demuestra la demo.
- Responsive para desktop/tablet/móvil.
- Sin login, sin backend y sin datos reales.

## Publicar en GitHub Pages

Subir la carpeta completa como repositorio. En GitHub: Settings → Pages → Deploy from a branch → `main` / root. El `index.html` raíz permite elegir entre los tres estilos.

Para publicar solo una estética, usar el contenido de la carpeta correspondiente como raíz del repositorio.
