# Nexo Operativo — 3 demos públicas

Tres versiones funcionalmente equivalentes de una demo pública de gestión operativa con datos 100% sintéticos.

## Versiones

1. `01_azul_futurista/` — SaaS tecnológico azul/cian.
2. `02_agro_editorial/` — editorial claro, verde/tierra.
3. `03_carbon_naranja/` — oscuro premium con naranja y esmeralda.

## Funcionalidades incluidas

- 28 gestiones sintéticas.
- 6 KPI, incluido monto completado.
- Atención sugerida con etiquetas comprensibles (sin P1/P2/P3/P4).
- Distribución por estado clickeable.
- Alertas y riesgos.
- Búsqueda global y filtros combinables.
- Tabla completa de gestiones.
- Drawer de detalle por caso.
- Exportación CSV de la vista filtrada.
- Explicación de qué demuestra y qué no demuestra la demo.
- Responsive para desktop/tablet/móvil.
- Sin login, sin backend y sin datos reales.

## Medición y validación

Desde el **2 de octubre de 2026**, la portada y las tres variantes utilizan
[GoatCounter](https://www.goatcounter.com/) para medir visitas de forma liviana y
orientada a la privacidad.

La medición permite:

- comprobar si la demo recibe tráfico;
- distinguir qué variante se visita;
- observar páginas vistas y fuentes de llegada cuando estén disponibles;
- generar evidencia para iterar el prototipo.

### Línea base

Las primeras **4 visitas** registradas corresponden a la verificación técnica de
la integración: una visita a la portada y una a cada variante. No representan
usuarios externos.

### Límites de interpretación

- Una persona puede generar varias visitas si abre más de una página.
- Las visitas no equivalen exactamente a personas únicas ni demuestran por sí
  solas que alguien haya probado las funciones.
- No existe información retrospectiva anterior a la instalación.
- Algunos bloqueadores de contenido pueden impedir el registro.
- El panel de estadísticas se mantiene privado.

Como siguiente iteración se evaluará medir eventos de interacción, por ejemplo:
uso de filtros, apertura del detalle de una gestión y exportación CSV.
